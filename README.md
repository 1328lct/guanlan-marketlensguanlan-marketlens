# 观澜 MarketLens｜A股市场状态研究台

第二题独立项目，未修改 AlphaRadar。面向A股研究者的可操作研究流程原型。**全部数值为合成 DEMO，不是真实行情；不是投资建议。**

## 运行与测试
需要 Node.js 20+，零依赖，无需安装包。

```
npm start
# http://127.0.0.1:4173
npm test
npm run build
```

可使用 `node server.mjs`、`node --test tests.mjs`、`node build.mjs`。dist/ 为静态托管目录。源码版本须通过HTTP打开；另提供 outputs/观澜-双击预览.html，将同一源码内联，可离线双击体验，无外部依赖。

## 用户与设计选择
研究者选择指数、区间并提出市场问题。界面以问题、证据和条件为主，避免行情交易终端暗示。七维框架为行情结构、宽度、风格、估值、流动性、情绪和事件。主链路：输入 → 意图识别/合规校验 → 显式取数计划 → 逐项异步DemoAdapter → 质量门禁 → 分层结果 → 点击证据回溯 → 进一步研究 → 导出/本地档案。首次打开自动执行一次标明DEMO的默认研究。所有输入改变会使旧结论失效。

## AI的角色
Codex参与设计、编码、核对与测试。运行时是确定性规则引擎，**没有在线LLM**；属于AI Native研究工作流演示，不能宣称具有开放式推理能力。自然语言支持市场、行业、风格、风险、历史主题的关键词识别，未知问题要求澄清。意图影响计划并披露延伸研究缺口，不伪造新增数据。

## 数据、口径与质量门禁
覆盖2025-06-01—06-20自然日的构造路径，不是真实交易日历。指数名称仅作构造样本标签。engine.mjs 中明确字段、来源、单位、范围、asOf、公式、callId。涨跌停、事件及估值也全为构造记录；不得用于真实市场结论。

宽度≥55%为扩散，<35%为收缩，否则分化。任一维异常为待确认，暂停整体归纳。充分度=可用维数/7×100，不是预测概率。部分有效字段仍可展示事实。缺失不补零，冲突双来源并列且排除，过期按固定样本时点注入，失败可重试（同一故障情境仍会失败）。这是可重复异常演示，不具备生产级自动过期检测与真实源冲突校验。条件连续性须有真实交易日数据后才能验证。
